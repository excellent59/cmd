# 🤖 ProLotBot

**ProLotBot** — это высокопроизводительный Telegram-бот, написанный на Go. Он предназначен для автоматического мониторинга автомобильных лотов с площадки [pro-lot.ru](https://pro-lot.ru). Бот собирает новые объявления, отслеживает изменение цен, синхронизирует удалённые лоты и отправляет красивые уведомления с фотографиями прямо в Telegram.

## ✨ Ключевые возможности

- **Умный парсинг**: Регулярный обход сайта с помощью `colly`. Бот умеет обходить защиту, извлекать VIN, номера кузова, год выпуска и цену, очищая данные от мусора.
- **Оповещения в Telegram**: Отправка сообщений в виде медиа-групп (альбомы до 10 фотографий).
- **Трекинг цен (Price tracking)**: Бот запоминает историю цен. При изменении цены подписчики получают уведомление формата «Старая цена / Новая цена» с индикатором тренда (🔴 повышение / 🟢 понижение).
- **Реконсилиация данных**: Если лот пропадает с сайта, бот автоматически удаляет его из базы данных и **стирает отправленные сообщения** в Telegram.
- **Встроенная Web-админка**: Полноценный SPA-дашборд, вшитый прямо в бинарник (`//go:embed`). Доступен по паролю (JWT-авторизация). В админке можно:
  - Смотреть статистику (всего лотов, отправленные, ожидающие).
  - Управлять настройками парсера "на лету" (интервал опроса, категории) без перезагрузки бота.
  - Просматривать список лотов и принудительно удалять их.
- **Надежность (Fault Tolerance)**: Атомарная фиксация отправки в БД (исключает дублирование сообщений при падении сервера) и корректное завершение работы (Graceful Shutdown).

## 🛠 Технологический стек

- **Язык**: Go 1.26
- **Архитектура**: Clean Architecture (Domain -> Usecase -> Delivery/Infrastructure)
- **База данных**: PostgreSQL 15 (драйвер `pgx/v5` с пулом соединений)
- **Миграции**: `golang-migrate` (автоматическое применение при старте)
- **Скрапинг**: `gocolly/colly/v2`
- **Telegram API**: `go-telegram-bot-api/telegram-bot-api/v5`
- **HTTP Server & Router**: `go-chi/chi/v5`
- **Авторизация**: `golang-jwt/jwt/v5` + защита от тайминг-атак (`crypto/subtle`).

## 🏗 Архитектура (Clean Architecture)

Проект строго разделен на слои для обеспечения высокой тестируемости и слабой связности:
- `cmd/bot/main.go` — точка входа, сборка зависимостей (DI).
- `internal/domain` — бизнес-модели (`Lot`, `Settings`, `ScrapeResult`) и интерфейсы.
- `internal/usecase` — бизнес-логика (сверка лотов, принятие решений об отправке/удалении).
- `internal/infrastructure/postgres` — работа с БД (сохранение лотов, транзакции, история цен).
- `internal/delivery` — внешние интерфейсы:
  - `/telegram` — логика отправки сообщений и альбомов.
  - `/scraper` — обход HTML-страниц.
  - `/http` — REST API и Web-админка.
  - `/scheduler` — динамический планировщик задач (ticker).

## 🚀 Установка и запуск

### 1. Подготовка окружения
Склонируйте репозиторий и скопируйте пример файла конфигурации (если есть) или создайте `.env` файл в корне проекта:

```env
TELEGRAM_TOKEN=ваш_токен_бота
TELEGRAM_CHAT_ID=-1000000000000
CATEGORIES=2,13,14,15,16,17,18
POLL_INTERVAL_MINUTES=60
DATABASE_URL=postgres://postgres:postgres@localhost:5432/prolotbot?sslmode=disable

# Admin Panel
ADMIN_PASSWORD=strong_password_here
JWT_SECRET=very_long_secret_string_here_32_chars
HTTP_PORT=:8080
```

### 2. Запуск базы данных
Если у вас установлен Docker, вы можете поднять базу данных с помощью `docker-compose`:
```bash
docker-compose up -d postgres
```

### 3. Запуск приложения
Загрузите зависимости и запустите бота. Миграции базы данных будут применены автоматически.
```bash
go mod download
go run ./cmd/bot/main.go
```
*(Для production рекомендуется собрать бинарный файл: `go build -o bot ./cmd/bot/main.go`)*

## 🔐 Доступ к админ-панели

После запуска перейдите в браузере по адресу:
`http://localhost:8080/` (или тот порт, что указан в `HTTP_PORT`).
Для входа используйте пароль из переменной `ADMIN_PASSWORD`.
